# 替换词典规范

脱敏工具用两个 CSV 文件决定「把什么换成什么」：

| 文件 | 管什么 | 谁维护 |
|---|---|---|
| **替换词典**（如 `词典.csv`，运行时用 `--dict` 指定） | 具体的名称：公司、集团、部门、人名、系统、项目、地址…… | 客户填写，随时增删 |
| **格式规则** `patterns.csv`（工具自带） | 有固定格式的信息：手机号、固定电话、身份证号、银行卡号、统一社会信用代码、邮箱、网址 | 一般不用改；需要时可加行或停用 |

两个文件都可以用 Mac 的 Numbers 或 Excel 打开编辑。保存时选 **CSV（UTF-8）**。

## 一、替换词典

### 表头（第一行，固定）

```
类别,原文,替换为,备注
```

| 列 | 必填 | 说明 |
|---|---|---|
| 类别 | 建议填 | 用于报告统计和自动编号。常用：`集团`、`公司`、`部门`、`人名`、`系统`、`项目`、`地址`、`其他`，也可以自定义 |
| 原文 | **必填** | 要替换掉的文字，按原样填写（全称、简称、别名各占一行） |
| 替换为 | 可留空 | 替换成的文字。**留空时自动编号**（见下文） |
| 备注 | 否 | 给人看的说明，工具不读 |

### 规则

1. **一行一个原文**。同一个对象的全称、简称、别名各写一行，「替换为」写同一个值：

   ```
   集团,华东示例控股集团有限公司,甲集团,全称
   集团,华东示例集团,甲集团,简称
   集团,华东示例,甲集团,更短的简称
   ```

2. **长的先匹配**。工具总是先匹配更长的原文，所以「华东示例」不会把「华东示例控股集团有限公司」截成半截。不用关心行的顺序。

3. **同一个原文只能对应一个替换值**。写了两行原文相同、替换值不同的，工具会报错并指出行号。

4. **留空自动编号**，按类别分别编号，顺序按词典中出现的先后：

   | 类别 | 自动编号 |
   |---|---|
   | 公司 / 单位 / 机构 | 甲公司、乙公司、丙公司……（超过 10 个后为 公司11、公司12……） |
   | 集团 | 甲集团、乙集团…… |
   | 人名 / 人员 | 人员A、人员B…… |
   | 其他类别 | 类别名 + 字母，如 系统A、项目B |

   **编号与行的先后有关**：不要在中间插行或调换顺序，否则同一个名称在两次运行中可能得到不同代号。新的条目加在末尾即可；想固定代号就直接填「替换为」。

5. **英文不区分大小写**：`HuaShi` 能匹配 `huashi`、`HUASHI`。

6. **注释行**：「类别」以 `#` 开头的行会被忽略，可以用来写说明或临时停用某一行。

7. **替换值不要包含原文**，例如不要把「华东」替换为「华东公司」，否则复查会判定为残留。

8. **文件名和文件夹名也会按词典替换**。如果两个原件替换后重名，工具会停下来提示，请调整词典。

### 扩展、修改

- **新增**：在末尾加一行。
- **修改替换值**：直接改「替换为」那一格。
- **停用**：在该行「类别」前加 `#`。
- 改完重新运行即可。每次运行都写入新的时间目录，旧结果不会被覆盖。

## 二、格式规则（patterns.csv）

表头：`名称,正则,替换为,启用,备注`

| 列 | 说明 |
|---|---|
| 名称 | 报告里显示的类别名 |
| 正则 | Python 正则表达式。**含逗号的正则必须用英文双引号括起来**（如 `"\d{16,19}"`） |
| 替换为 | 命中后替换成的文字，如 `【手机号】` |
| 启用 | `是` / `否` |

自带规则：身份证号、统一社会信用代码、手机号、固定电话（带区号和短横线）、银行卡号（16–19 位连续数字）、邮箱、网址。

注意：「银行卡号」规则会把所有 16–19 位的连续数字都替换掉。如果制度里有这类长数字而且不敏感（比如某种编号），把这条规则的「启用」改为 `否`。

**词典优先于规则**：同一段文字既在词典里又能被规则命中时，按词典替换。

## 三、金额、天数、比例

当前版本**不替换数字**，金额、天数、比例保持原样。如果客户认定某些数字属于机密，有两种做法：
- 个别数字：在词典里按原文写出（如 `其他,年薪 85 万元,年薪【金额】`）；
- 成批数字：需要另加规则，请先和我们确认替换方式（统一占位，或按比例换算）。
